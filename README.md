# StudySync
A student productivity and assignment management portal built using Python and Django.


1. Business Goals

Centralize academic tasks and information.

Improve student productivity and organization.

Reduce missed deadlines and assignments.

Provide personalized academic management.

Simplify everyday academic planning.


2. Epics

User Authentication

Student Dashboard

Task Management
Deadline Management
Progress Tracking
3. User Stories
As a student, I want secure login.
As a student, I want a personalized dashboard.
As a student, I want to manage tasks.
As a student, I want to track deadlines.
As a student, I want to monitor progress.
4. Tasks
Set up Django project and database.
Develop user registration and login.
Create the student dashboard.
Implement task CRUD functionality.
Add deadline and progress tracking.
